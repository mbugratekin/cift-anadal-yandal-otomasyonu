# Çift Ana Dal / Yan Dal Öğrenci Takip Otomasyonu

Mehmet Buğra Tekin

ASP.NET Core MVC, Entity Framework Core ve SQL Server ile hazırlanmıştır.

Canlı uygulama: https://mehmetbugratekin-001-site1.ftempurl.com/

Test hesapları öğretim elemanına ayrı olarak iletilir. Parolalar ve canlı bağlantı ayarları bu depoda bulunmaz. E-posta işlemleri canlı ortamda etkin değildir.

Yerelde çalıştırmak için .NET 10 SDK ve SQL Server gerekir. Bağlantı ayarını kullanıcı sırları veya ortam değişkenleriyle tanımlayın. Bu depo canlı veritabanını ve belge deposunu içermez.
